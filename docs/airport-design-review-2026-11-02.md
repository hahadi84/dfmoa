# 공항 디자인 공통 적용 검토 — 2026-11-02

## 변경
- 홈페이지에만 적용되던 공항 분위기를 루트 공통 스타일로 확장. 남색 안내판, 노란 강조색, 밝은 본문과 흰 카드, 일관된 버튼과 제목을 한국어·영어·일본어·중국어에 적용.
- 공통 모바일 메뉴 추가: 언어별 메뉴 버튼, 펼침 상태 알림, Escape 닫기 및 포커스 복귀, 링크 선택 시 닫기. 1100px 이하에서 접힘.
- 기존 쇼핑백 DF 도형을 유지하고 로고/SVG/PNG/ICO/Apple 아이콘을 노랑·남색으로 통일, 캐시 버전 변경.
- 지나치게 굵은 800/900 글꼴을 700으로 조정. 시스템 다크 모드에서도 같은 밝은 본문/남색 안내판 팔레트를 유지.
- 가격·혜택 데이터, 검색 메타데이터, 광고 슬롯·로드 조건은 변경하지 않음.
