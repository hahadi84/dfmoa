# DFMOA 외국어 쇼핑 이미지 보강 프롬프트

아래 프롬프트는 영어·일본어·중국어 간체 페이지에 공통으로 사용한다.

```text
DFMOA 외국어 쇼핑 가이드의 이미지를 보강해 줘. 모바일 여행자가 상품 포장을 식별하고, 지점 입구를 찾고, 주문한 판매처의 인도장으로 이동할 수 있어야 한다.

1. 먼저 현재 세 언어의 상품 목록·상세, 설화수 90ml 비교, 명동 매장, 부산역 동백상회, 김해공항 수령 안내를 열어 본문 이미지와 공유 미리보기를 따로 점검해. 페이지별로 사진이 답해야 할 질문을 하나씩 정해.

2. 상품은 기존 검증된 가격 기록에서 브랜드·제품명·세대·용량·농도·수량이 같은 판매 항목의 이미지만 사용해. 검색 결과 첫 사진이나 다른 규격의 기획 세트는 제외해. 한국어 페이지의 기존 이미지 컴포넌트, 오류 대체 표시, 동일 상품 데이터를 재사용해. 판매처 이미지의 권리·표시 조건을 기록하고 근거 없이 외부 사진을 새로 저장하거나 공유 카드로 배포하지 마.

3. 지역 가이드는 직접 촬영한 사진이나 상업적 웹 게시가 허용된 자료를 우선해. 명동은 한글 지점명이 보이는 입구, 부산역은 광장에서 역사를 바라본 방향의 유라시아플랫폼 1층 106호 표지, 김해공항은 판매처와 층을 판독할 수 있는 현행 안내도를 찾아. 촬영·게시 권한과 현재 위치를 확인해. 실제 매장이나 인도장을 AI로 재현하지 마. 확보하지 못하면 공식 지도 링크를 남기고 필요한 촬영 장면을 편집 목록에 기록해.

4. 각 자산에 원본 URL·제공자·이용 조건·출처 표기·확인일·대상 지점 또는 상품 규격을 기록해. 길찾기 사진에는 세 언어로 화면에 실제 보이는 표지와 다음 행동을 설명하는 캡션을 붙여. 바로 옆 상품명과 같은 정보를 반복하는 작은 썸네일은 장식용으로 처리해.

5. 공유 이미지 자체 사용 권한이 확인된 페이지에는 주제별 1200×630 대표 이미지를 연결해. 본문 사진과 공유 카드를 각각 검증해. 가격이나 재고처럼 빨리 바뀌는 정보는 카드에 넣지 마.

6. 360px 화면에서 이미지 비율·본문 밀림·확대 판독성, 이미지 404·차단 시 대체 표시, 이미지 로딩 전에도 가격·지도 링크를 쓸 수 있는지 확인해. 정적 HTML의 이미지와 공유 태그를 검사하고 로컬 빌드해. 페이지별 반영 결과, 검증 범위, 추가 취재할 자산을 한국어로 보고해.
```
