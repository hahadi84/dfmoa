# 釜山車站伴手禮哪裡買？搭 KTX 前逛冬柏商會

搜尋問題：搭車前想買釜山特色小禮物，要進站還是去站前廣場？
搜尋摘要：從 KTX 站房走到站前廣場，找歐亞平台一樓的冬柏商會。比較釜山地標小物與海鷗麵包，附可複製的韓文地址。

先走出 KTX 站房。站在歐亞平台廣場面向車站，找一樓 106 室的「동백상회」。如果沒看到招牌，可查看廣場導覽圖。出發前先看車票上的發車時間，留足回站搭車的時間。
