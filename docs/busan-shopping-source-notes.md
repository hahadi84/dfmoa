# 부산 쇼핑 가이드 편집 메모 · 2026-11-05 KST

## 부산역

- [부산시 개점 자료(2020)](https://www.busan.go.kr/eng/bsnews01/1465038)와 [시 영문 신문](https://www.busan.go.kr/bige/daily-busan/view?bbsNo=10&dataNo=68146)을 대조했다. 영문 기사의 중앙대로 206 역사 2층 신맞이방은 6월 8일까지 운영한 행사 매장이다. 같은 기사에서 상설 동백상회를 중앙대로 210 유라시아플랫폼 1층으로 별도 안내했다.
- [2026-09-22 부산시보 현장 기사](https://www.busan.go.kr/news/storyreport/view?curPage=3&dataNo=73316)는 ‘부산역 1층’으로 요약한다. [한국관광공사](https://english.visitkorea.or.kr/svc/contents/contentsView.do?dataSetId=120&menuSn=929&vcontsId=1590968)의 상세 주소는 유라시아플랫폼 1층 옥외 구역 106호이며 [비짓부산](https://www.visitbusan.net/index.do?lang_cd=ko&menuCd=DOM_000000201013001000&uc_seq=1308)은 광장에서 역사를 바라보는 접근 방향과 같은 호실을 안내한다. 이 두 자료를 방문 경로의 기준으로 삼았다.
- 비짓부산이 해당 지점에서 소개한 자개 문양 부산 명소 상품과 갈매기빵만 수록했다. 당일 영업·재고, 개당 가격, 포장 수량, 제조지, 역사에서의 소요 시간은 현장 확인 대상이다. 상설점 단독 공식 웹페이지를 확인하지 못해 공식 매장 정보 버튼은 한국관광공사의 지점 소개로 연결했다.

## 김해공항

- [신라 인도장](https://www.shilladfs.com/comm/kr/en/shoppingGuideStep3), [신라 주문 FAQ](https://www.shilladfs.com/comm/kr/en/faqList), [롯데 상품 페이지의 인도 안내](https://eng.lottedfs.com/kr/product/productDetail?prdNo=20000807461)에서 김해 국제선 출국 수령과 판매처별 위치·서류를 대조했다. 다음 정기 공개 전에 판매처 안내 변경과 롯데 상품 링크 만료 여부를 재확인한다.
- 실제 항공편·계정으로 주문하지 않았다. 상품별 마감·주문 가능 여부는 여행자의 출발 정보와 주문서로 판단한다. 도착편과 부산항은 이 가이드 범위 밖이다.
