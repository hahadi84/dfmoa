# 혜택 페이지 광고 개선 — 2026-10-30

상태: 로컬 수정, 배포하지 않음. 사용자의 주 1회 공개 정책 유지.

## 추가 검토
- `/benefits/`처럼 끝 슬래시가 있는 경로도 동일하게 허용한다. 개인정보 페이지 제외는 유지한다.
- 서버 초기 렌더링에는 공간만 예약하고 개발용 회색 플레이스홀더를 표시하지 않는다. 브라우저에서 비운영 도메인으로 확인된 경우에만 플레이스홀더를 표시한다.
- 관련 회귀 테스트 11개 통과. 수익 효과와 실제 운영 광고 노출은 미검증이다.

## 변경
- `/benefits`를 광고 콘텐츠 경로에 추가했다.
- 행사 데이터가 있을 때만 제목·소개·확인일 아래에 기존 top 슬롯 한 개를 배치한다.
- 이 경로에서는 공통 헤더 아래 배너를 생략해 수동 광고가 중복되지 않는다.
- 회사 선택과 상세 필터보다 앞에 별도 영역으로 배치한다. 기존 광고 라벨, 24px 여백, 모바일 100px/데스크톱 90px 공간 확보를 유지한다.
- 운영 도메인 제한, 중복 push 방어, 로컬 플레이스홀더를 유지한다.

## 기준치와 측정
사용자 제공 AdSense 화면의 최근 7일: 약 2,360 페이지뷰, 예상 수익 $0.49, 광고 노출 749, 페이지 RPM $0.21, 클릭 3, 페이지 CTR 0.13%. 상단 수동 슬롯 174회/$0.06, 결과 슬롯 20회/$0.00. 날짜 범위 원본 및 Active View는 확인되지 않았다.

이 수치는 사이트 전체 기준이며 혜택 페이지의 이전 성과로 대체할 수 없다. 노출/페이지뷰 비율은 충족률이나 Active View가 아니다.

공개 후 혜택 페이지의 방문·참여·공식몰 이동과 AdSense 페이지/광고단위별 RPM, Active View, 요청·노출을 가능한 보고서 범위에서 확인한다. 공개일을 표시하고 이후 28일과 이전 28일을 비교한다. 행사 교체, 유입 국가·기기·방문량 차이 때문에 단순 수익 차이를 변경의 인과 효과라고 단정하지 않는다. 상단 슬롯은 기존 페이지와 공유하므로 슬롯 전체 수익만으로 혜택 페이지 효과를 분리할 수 없다.

## 남은 검증
- 실제 운영 광고의 채움·모바일 겹침·자동광고와의 간격은 승인된 공개 후 확인한다. 로컬에서는 실제 광고를 호출하지 않는다.
- AdSense의 페이지 제외 목록에 `/benefits`가 포함되는지 확인 필요. 계정 설정은 변경하지 않았다.
- 결과 광고 위치 변경 및 진단 집계는 이번 변경에 포함하지 않았다. 먼저 누락 보완의 성과를 관측한다.
- 수익 상승 또는 특정 RPM·CTR를 보장하지 않는다.
