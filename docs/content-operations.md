# DFMOA 콘텐츠 운영

## 발행과 갱신
- 기존 GitHub Actions `snapshot.yml`이 매일 07:00 KST 실행될 때 `scripts/content-refresh.mjs`를 실행한다. 예약 실행은 GitHub 사정에 따라 지연될 수 있다.
- 현대면세점 공개 행사 목록의 행사명과 명시적 시작일/종료일을 확인해 당일 유효한 행사만 최대 6개 수록한다. 별도 자격 검토가 필요한 카드 발급 캐시백은 제외한다. 이는 행사 상세 조건 검증이나 모든 면세점 전체 혜택 목록이 아니다.
- 월간: 매월 첫 성공 수집 때 새 호를 만들고, 같은 달에는 행사 변경 시 갱신한다. 최초 발행일과 이전 월 기록은 보존한다.
- 주간: 한국 시간 월요일부터 새 주로 본다. 첫 성공 수집에 한 번 발행하며, 해당 주 재실행은 새 호를 만들지 않는다. 이전 호의 내용은 수정하지 않는다.
- 수집 실패·기간 추출 실패 시 새 보고서를 만들지 않는다. 이전 정상 자료를 보존하고 작업을 실패로 표시한다. 지난 자료의 확인일을 오늘로 바꾸지 않는다.
- ECB 기반 JPY/KRW 참고 환율을 Frankfurter에서 매일 수집한다. 7일 이상 오래된 응답·잘못된 통화·비정상 숫자는 거부한다. 공개 페이지에는 실제 기준일과 참고 환율임을 표시한다.
- `data/content/`의 JSON을 Git에 기록하면 Netlify 기존 Git 연결이 배포한다. RSS와 사이트맵에 새 페이지가 자동 반영된다.
- 이메일 발송은 이 작업 범위에 포함하지 않는다. 사이트와 RSS에 발행한다.

## 검증
`node --test scripts/content-refresh.test.mjs`는 기간 경계, 공식 도메인, 한국 시간 월 경계, 주간 중복 방지, 월 변경, 실패 보존을 검증한다.
`node scripts/content-refresh.mjs`로 수집을 재실행한다. 같은 주에 강제로 새 글을 생성하지 않는다.

## 일본 여행 검색 유입
핵심 페이지 `/japan`: 100엔 원화 환산, 현지 결제액/환급 후 비용, 국내 면세가 비교.
지원 글: 엔화 환율과 면세가 비교, 2026년 일본 면세 환급 변경, 일본 쇼핑 상품 비교 체크리스트.
검색량·클릭 단가가 검증된 순위는 아니다. 일반적인 여행 정보보다 구매 비교 의도에 맞춘다.
홈과 메뉴→일본 쇼핑→가이드/계산기→카테고리/가격 비교→월간·주간 혜택으로 연결한다.
후속 후보: 엔화 100엔 계산, 일본 향수 면세 가격 비교, 일본 SK-II 국내 면세 비교, 히비키 일본 가격 비교. 실제 동일 상품 가격·재고·날짜가 확보된 경우에만 구체 가격을 작성한다.
Search Console 접근 시 28일 단위로 일본 관련 검색어 노출·클릭·CTR·순위와 `/japan` 유입을 비교한다. 데이터가 없을 때 유입 증가를 단정하지 않는다.
