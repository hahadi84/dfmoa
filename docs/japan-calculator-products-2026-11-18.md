## 변경

- `/japan`: 예시 가격 기본값을 제거하고 실제 두 가격 입력·명시적 비교 실행 시에만 결과를 표시한다. 입력 수정 시 이전 결과를 숨긴다. 0원·음수·공란·환급 초과·수수료 범위 초과·무한 계산값은 제외한다.
- `effective_price_calculate` 재사용. `source_page=japan`, `calculator_type=yen_comparison`, `language=ko`, `interaction=calculate_submit`, `has_fee`, `has_refund`를 전송한다. 입력 금액 자체·개인정보는 보내지 않는다. 동일 숫자 조건의 연속 제출은 한 번만 기록하고 변경 조건을 다시 제출하면 새 계산으로 기록한다. 새 페이지 방문 후 계산은 별도 행동이다.
- `/guide/japan-shopping-price-checklist`: 기존 3개 상품 식별자를 사용해 규격·추천 이유·가격 종류·통화·공식 판매처·언어·관찰일·할인 조건·구매 경로를 추가했다. 비교표와 상품 바로가기, 상품 비교·계산기·공식 출처 링크 제공.
- `/guide/yen-rate-duty-free-comparison`: 대표 상품 비교표로 연결. 사이트맵 변경일 11월 18일 반영.
- 기존 `shopping_product_open`, `shopping_compare_open`, `shopping_branch_open`을 사용하고 상품 slug·페이지·언어를 구분한다. 공식 자료 열기는 `interaction=official_product_source`이며 구매 완료로 해석하지 않는다.
- 가이드의 최초 발행일을 보존하도록 선택적 `publishedAt`을 추가했다. 해당 글 발행일 10월 23일, 수정일 11월 18일. 근거 없는 Product/Offer/평점은 추가하지 않았다.
